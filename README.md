# CTRL+Z — code du jeu

*English below.*

CTRL+Z est un jeu de survie en 3D contre des hordes de robots, développé par Femz. Il sera vendu sur Steam.

Ce dépôt contient le **code du jeu en lecture** (`src/`, `index.html`, `ui.css`). Il est mis à jour automatiquement
à chaque nouvelle version : un commit par version, nommé d'après les notes de version.

**Le jeu ne se lance pas depuis ce dépôt** : les sons, musiques, polices, images et modèles 3D n'y sont pas
publiés. Pour jouer, rejoins le Discord.

## Proposer une modification

- Un bug ou une idée → ouvre une **issue**.
- Une correction ou une amélioration du code → ouvre une **pull request**. Ce dépôt n'est qu'une copie : les
  propositions acceptées sont reprises à la main dans le dépôt principal et arrivent dans une prochaine version.
- Pour accéder au salon des développeurs sur le Discord, demande le rôle **Développeur** à Femz.

Discord : https://discord.gg/RSJ3jEPGGZ
